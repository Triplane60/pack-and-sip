Pack & Sip — B2B Wholesale Packaging Platform

A modern, light-weight B2B e-commerce platform designed for bulk packaging suppliers. Built with a Python backend architecture and deployed live on Render.

🚀 Live Application:= [packandsip.onrender.com](https://packandsip.onrender.com)

---

 📌 Features

- Bulk Catalog Management Organized view for drinkware (cups, lids) and food packaging (microwavable containers) with MOQ tracking.
- Dynamic Inventory Indicators: Real-time visual status for `In Stock` and `Out of Stock` items.
- B2B Wholesale Pricing Logic: Automated price calculation per box/bulk unit.
- Interactive Cart System: Floating cart overlay with responsive item counts and dynamic total calculation.
- Logistics Integration Ready: Built to support warehouse dispatching and flexible self-booking/courier options (e.g., Lalamove).

---

 🛠️ Tech Stack

- Backend:Python (Flask / FastAPI)
- Frontend: HTML5, CSS3, JavaScript (Clean & Light-weight UI)
- Deployment & Hosting: Render (Cloud Web Service)
- Version Control: Git & GitHub

🏗️ System Architecture & Workflow

1. Client Interface: Renders dynamic packaging catalog with instant filtering and search.
2. Order Processing Engine: Validates bulk quantities, updates pricing logic, and handles cart state.
3. Deployment Pipeline: Automatic deployment triggers via Git integration hosted on Render web services.
